# Changelog

## v0.7.0
- `kerna check`: what kerna can and cannot see on this machine (no host name or user name), for bug reports.
- Shell completion: `kerna completion fish|bash|zsh`.
- `kerna watch`: `?` shows all keys, the key list never wraps and scrolls the screen on narrow terminals, long commands wrap with a hanging indent.
- History evidence is stored in English and Turkish, so it reads in your language whichever language the recorder ran in.
- Arch packaging file (`packaging/arch/PKGBUILD`), issue templates, CONTRIBUTING and SECURITY.

## v0.6.0
- `kerna why <name|pid>`: one program, now versus its whole life, threads, GPU, wake-ups, children.

## v0.5.0
- GPU time per program from DRM fdinfo; the `gpu-load` finding; `GPU users` row.

## v0.4.0
- `watch` keys (select, copy, mute, programs panel, today), `history --today`, `sleep`, network findings, process descriptions, Quickshell example.

## v0.3.0
- `ignore` and config, Waybar module, notifications, `snapshot`/`compare`, `why-froze`, power profile finding.

## v0.2.0 / v0.2.1
- Battery suspects by wake-ups, Intel GPU busy, amdgpu watts; the NVIDIA Runtime D3 status.

## v0.1.0
- First release: PSI based findings, live view, history, installer.
